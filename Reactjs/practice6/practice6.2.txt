✅ Heavy calculations

filtering 10,000 products
sorting large arrays
complex math calculations

✅ Prevent unnecessary recalculations

When NOT to use it?

❌ Simple calculations

Why do we need it?

Consider this:

function App() {
  const [count, setCount] = useState(0);

  const handleClick = () => {
    console.log("Button clicked");
  };

  return (
    <>
      <button onClick={() => setCount(count + 1)}>
        Increment
      </button>
    </>
  );
}

When count changes:

App re-renders
↓
handleClick is created again

Even though the code is the same, JavaScript creates a new function object.

With useCallback
import { useCallback } from "react";

const handleClick = useCallback(() => {
  console.log("Button clicked");
}, []);

Now React remembers the function.

Re-render
↓
Same function reused
